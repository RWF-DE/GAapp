# 用語と業務ルール

## 用語集

コード上の名前は「英語名」列にそろえる。画面の表示は日本語のまま使う。総務アプリ全体の用語（機能・ダッシュボードなど。表の最後）と、机椅子の機能の用語がある。この文書の業務ルールと年間の業務の流れは、机椅子の機能のもの（D-51）。ほかの機能（T17〜）の用語は、その機能のチケットが表の最後に足す（D-52）。

## 業務ルール

机椅子の機能のルール。ルールは2種類ある。「固定」はコードに書き、「設定」は部門長以上（管理者・総務部門長・総務副部門長。D-48）が年ごとに画面で変える。R8で決めたことは「設定」の初期値として登録する。設定ルールのコードは、年度名（R8・R9）と紛らわしくないよう S01〜 とする。

**固定ルール（変えられない）**

1. 保管場所・品目ごとに、振り分け合計（残すを含む）は在庫を超えない
2. 使用不可の部屋からは振り分けない
3. 申請は、団体・申請品目ごとに過不足なく満たす（代替を含む）
4. キャスター机への置き換えなどの代替は、その品目の在庫が足りないときだけ使い、代替の重さ（ルールの cost。キャスター机は 3、長机(3人掛)→(2人掛) は 1）の合計を最小にする。ただし不可机・不可椅子は、使ってよい区分では普通の机(木)・椅子(木)と同じ扱いにする（S01・S02）
5. その上で、運ぶ距離を最小にする。距離が同じなら、運び出す台数が少ない方（残す方）を選ぶ。団体の使用場所にある備品は距離0なので、その団体が残して使う。自室の備品を外へ出して、同じ品目を別の部屋から運び込む結果は出さない（検証 W107。運び元の制限（S05）などで入れ替えられない場合と、入れ替えると運ぶ距離が長くなる場合は除く）
6. 振り分けの数は1以上の整数
7. 予備の台数は持たない。使わなかった分がそのまま余りになる
8. 企業のメールアドレスなど、外部の個人情報は保存しない

**申請の扱い**

- 申請できるのは、品目マスタの「申請できる区分」にその団体の区分が入っている品目だけ。備考での読み替え（R8の「長机をキャスター机3個×2に変更」など）は認めず、団体に申請を直してもらう
- 備考は団体ごとに1つ。数には影響しない
- 締切後の変更は総務（部門長以上）が入力し、理由を履歴に残す（R8では剣道部の机2・椅子1の追加など）
- 同じ団体が屋内と屋外の両方で使う場合は、使用場所ごとに別団体として登録する。R8の剣道部は、振り分け表では1団体、配布スケジュールでは「剣道部(飲食)」「剣道部(非飲食)」に分かれていた
- 企業ブースと休憩所は、総務（部門長以上）が代わりに申請を入力する。休憩所は前年の数を初期値にする
- 正面ゲートで使う分は装飾の申請に含める（R8の運用。ルールとしては持たない）
- Googleフォームの回答を取り込むときの扱いは、[画面とAPI](04_screens_api.md)の「CSV取り込み」に従う

**毎年見直す項目**

- 使用不可の部屋、設営の台数、休憩所の有無と場所（R8はHI棟前を廃止、テニスコート前・ロボコン前を追加）
- 企業ブースの企業と場所
- 各部門の配布時刻（総務スケジュールに合わせる）
- 運び出しにくい部屋の追加コスト（R8で「4号棟より遠い」とされたCI5など）

## 年間の業務の流れ

机椅子の機能は次の順に使う。括弧内は年度ステータスと主な担当。ダッシュボード（/）の要対応の一覧が、この流れの次の作業（2〜6 と、9 の年度の終了。1 の年度の作成と、フェーズ2の 7・8 と返却チェックは出さない。前々日・前日などの日付は「締切と予定」に出る）を立場ごとに出す（04「机椅子の状況」の「ダッシュボードに出すもの」）。

1. 7月：Supabase のプロジェクトが一時停止していれば管理画面から再開する。年度を作り、前年度の団体・ルール・使用不可の設定を複製して直す。ロールは年度ごとで、年度の複製は作った管理者のロールしか作らないので、管理者が毎年、総務部門長・総務副部門長（と、ほかの管理者・閲覧のみ）を招待し直す。総務部門員と団体代表（店長・副店長）は、管理者か部門長・副部門長が招待する（preparing、管理者・部門長以上）
2. 在庫を数える。部員が保管場所ごとにスマホで入力する（preparing、部員）
3. 申請を受け付ける。企業・休憩所は総務が代理入力する（requesting、団体代表）
4. 締切後、自動振り分けを実行し、検証結果を見ながら手で直す（allocating、部門長以上）
5. キャスター机に置き換えた団体に交換を依頼し、了承を記録する。了承した置き換えは固定される。了承しなかった団体があれば、その団体を置き換えの対象から外して「最小変更」で再実行する（allocating、部門長以上）
6. error 0 件で確定し、振り分け表を部門員に共有、団体に公開する（confirmed、部門長以上）
7. 配布スケジュールを作る（confirmed、部門長以上、フェーズ2）
8. 前々日：仕分け、設営・FE などの部門と企業への配布。前日：テント・模擬店・残りの部門への配布（confirmed、部員が運搬チェック、フェーズ2）
9. 祭の後、元の部屋に戻して返却チェック（部員）。管理者が年度を終了（closed）にし、年度データを書き出して総務の共有ドライブに保存する。ルールの見直し点をメモに残す（closed、管理者・部門長以上）

確定後に変更が出たとき（R8の第一セミナーのように）は、確定を解除して 4 に戻り、「最小変更」で再実行する。手で直した行、固定した行、了承済みのキャスター机交換は変わらない。
