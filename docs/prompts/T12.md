# T12 画面：ルール設定
推奨：モデル sonnet ／ effort medium

目的：/rules を作り、4種類のルール（substitute・source_restrict・fixed_request・keep）を、種別ごとのフォームで追加・編集・有効化できるようにする。

前提：
- 03_allocation.md の「ルールの params と扱い」、04_screens_api.md の「ルール」、画面の設計書の 3.8。
- 画面の設計書 notes/T09a-design/ui-design.md（1・2 章：構成とデータの読み書き、7 章：テスト）と、T09a の共通基盤（components/ui・components/common、lib/db・lib/rpc・lib/errors.ts・lib/data・lib/schemas/common.ts、e2e/support）を使う。共通の部品が足りなければ自分の画面のディレクトリ（components/<画面>/）に置き、common/ に移すのは2つ目の画面が要るときに後のチケットで行う。
- params は packages/shared の ruleRowSchema で形を、checkRuleRefs（RuleDraft と、自分以外の有効なルール）で参照と重なりを確かめてから保存する。団体・場所は名前から選び、id で保存する。品目はコードで持つ。保存は rules への直接の書き込み（updated_at で楽観ロック）。削除は出さない（無効にする。無効のルールも次の年度に引き継ぐ）。確定中と終了した年度はメモだけ（確定中は DB が書き込みを許すが、画面で止める）。

範囲：app/(app)/rules、components/rules、lib/data/rules.ts（describeRule を含む）、e2e/t12-*.spec.ts、e2e/shots/T12.shots.ts、notes/T12.md・notes/T12/、04 の「ルール」の節。packages/shared は変えない（足りなければ notes に書いて相談する）。ほかの画面のディレクトリ、apps/web/package.json・pnpm-lock.yaml、lib/navigation.ts、app/layout.tsx、playwright.config.ts、e2e/support は触らない（T09a が持つ。足りなければ notes に書いて相談する）。

完了基準：
- S01〜S08 を画面から登録でき、保存した params が fixtures/r8/rules.json（なければ fixtures/synthetic/r8like/rules.json）を id に直したものと一致する（Playwright。`createScenario({ dataset: 'synthetic', rules: 'none' })` の年度で）。
- 重なる・参照の切れたルールは、欄の下にエラーが出て保存できない。`?code=S05` でその行が開く。削除のボタンはなく、無効にできる。確定中はメモだけ直せる。
- describeRule の Vitest。
- `pnpm lint`・`pnpm typecheck`・`pnpm test`・`pnpm build`・`pnpm e2e` が通る。E2E はシナリオの年度（e2e/support の createScenario）で閉じる。seed の R8 の年度のロールと未招待のユーザーは変えない（seed のユーザーにはシナリオの年度にだけロールを付けてよい。ロール・招待を変えるテストは createUser のユーザーで。年度をまたぐ表は serial でだけ変える。D-36）。
- 実際に起動して確かめ、スクリーンショット（PC とスマホ、読み込み中・空・権限なし、主なダイアログ）を `pnpm e2e:shots --grep "<チケットID> "`（ID の後に空白を入れて絞る。ID だけだと、T09 が T09a のテストにも当たるように、ID で始まるほかのテストにも当たる） で notes/<チケットID>/ に残す。

出力：変更ファイル一覧、実行したコマンドと結果、スクリーンショット。

---
終わったら：reviewer サブエージェントでレビューする（正しさと要件に関わる指摘だけ）。認証・RLS・RPC・入力処理に触れたら security-reviewer にも回す。指摘を直してから PR を作る。05_development.md のチケット表の「状態」と notes/decisions.md は直さず、新しい決定は notes/<チケットID>.md に書く（並行するブランチで隣の行を変えて衝突するため。マージの後にまとめて直す。D-32）。
