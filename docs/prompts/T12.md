推奨：モデル sonnet ／ effort medium

目的：/rules を作り、4種類のルール（substitute・source_restrict・fixed_request・keep）を、種別ごとのフォームで追加・編集・有効化できるようにする。

前提：
- 03_allocation.md の「ルールの params と扱い」。
- params は packages/shared の zod スキーマで検証してから保存する。団体・場所は名前から選び、id で保存する。品目はコードで持つ。

範囲：apps/web の /rules と、packages/shared の params スキーマ（T06 で作っていればそれを使う）。

完了基準：S01〜S08 を画面から登録でき、保存した params が allocator のテストで使っている形と一致する。`pnpm build` が通る。

出力：変更ファイル一覧、実行したコマンドと結果。
