# T08 exporter：Excel と年度データ
推奨：モデル sonnet ／ effort medium

目的：R8 と同じ様式の振り分け表（xlsx）、キャスター机交換依頼一覧、年度データ（JSON）を出力する関数を作る。

前提：
- 03_allocation.md の「Excel出力仕様」。
- R8 の実物（最終の振り分け表 xlsx）はリポジトリの外（`R8_SOURCE_DIR`）にあるので、様式の確認に使ってよい。（注：D-40 により R8 の元データは使わない。様式は 03_allocation.md の「Excel出力仕様」に従う。）
- ExcelJS は数式を計算しないので、計算済みの値も書き、fullCalcOnLoad を設定する。

範囲：packages/exporter。ブラウザでも Node でも動くこと。画面からの呼び出しは T13。

完了基準：
- fixtures/r8 の振り分け（参考）から出力した xlsx を LibreOffice の headless で再計算し、数式エラー0件・「在庫超過」「要確認」0件、団体別集計が fixtures の値と一致する（CI で実行する）。（注：D-40 により fixtures/r8 は作らないので、合成データ fixtures/synthetic/r8like の reference/ で確かめる。fixtures/r8 を作ることになれば、同じテストがそちらにも流れる。）
- 机(木)・椅子(木)のシートで、同じ（運び元・運び先・団体）の普通の行と不可の行が1行にまとまっている。
- 使用不可の部屋が「残す／使用不可」の1行で出る。
- 年度データの JSON にメールアドレスが含まれない。

出力：変更ファイル一覧、テスト結果。
