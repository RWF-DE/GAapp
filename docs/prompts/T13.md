# T13 画面：振り分け・キャスター机交換・自団体の振り分け
推奨：モデル sonnet ／ effort medium ／ 計画モードで開始

目的：/allocation（中心の画面）、/swaps、/my を作り、自動振り分けから確定・出力までを画面で行えるようにする。

前提：
- 04_screens_api.md の「振り分け」「キャスター机交換」「自団体の振り分け」。
- 計算は Web Worker で allocate() を呼ぶ。保存は save_auto_allocations、行の編集は save_allocation_rows（楽観ロック）、了承は set_consent、確定は set_year_status。
- highs-js の wasm は振り分け画面でだけ読み込む。

範囲：apps/web の該当ページと Web Worker。allocator と exporter のロジックは変えない（バグを見つけたら別のチケットにする）。

完了基準：
- fixtures/r8 を入れた状態で、自動振り分け → 検証の error 0 件 → 確定 → Excel 出力ができる（Playwright）。
- 計算中は画面がロックされ、解けないときは不足と原因が表示される。
- 了承を「拒否」にして最小変更で再実行すると、その団体の置き換えが消える。
- 別の管理者が先に行を変えていたら「他の人が変更しました」と出て、読み直す。
- 団体代表の /my で、確定前は申請内容と交換の依頼、確定後は運び元と数が見える。
- `pnpm build` が通る。スクリーンショットを notes/T13/ に残す。

出力：変更ファイル一覧、実行したコマンドと結果、スクリーンショット。
