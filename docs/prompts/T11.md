# T11 画面：申請と申請一覧・CSV 取り込み
推奨：モデル sonnet ／ effort medium

目的：/request（スマホ、団体代表）と /requests（PC、総務）を作り、フォーム回答の取り込みを画面から使えるようにする。

前提：
- 04_screens_api.md の「申請」「申請一覧」「CSV取り込み」。
- 申請できる品目は items.requestable_categories で絞る。締切後の修正は update_requests_after_deadline（理由が必須）。

範囲：apps/web の該当ページ。importer（T05）を呼ぶだけで、取り込みのロジックは変えない。

完了基準：
- 団体代表が申請を提出し、締切前なら修正でき、締切後は読み取り専用になる（Playwright）。
- 企業以外の団体には、長机(3人掛)の入力欄が出ない。
- 総務が締切後に理由つきで修正すると、audit_logs に理由が残る。
- 匿名化したサンプルのフォーム回答を取り込むと、対応できなかった行が一覧に出る。
- `pnpm build` が通る。スクリーンショットを notes/T11/ に残す。

出力：変更ファイル一覧、実行したコマンドと結果、スクリーンショット。

---
終わったら：reviewer サブエージェントでレビューする（正しさと要件に関わる指摘だけ）。認証・RLS・RPC・入力処理に触れたら security-reviewer にも回す。指摘を直してから PR を作り、docs/requirements/05_development.md のチケット表の状態を更新する。
