# T00 スパイク：highs-js で R8 規模の輸送問題を解く
推奨：モデル sonnet ／ effort medium

目的：highs-js（ブラウザで動く HiGHS）で、03_allocation.md の定式化どおりの輸送問題が R8 規模（保管場所 約40 × 団体 約55 × 品目9、代替あり）で何秒で解けるか、解が整数で返るかを確かめる。本番のコードではなく、T06 の判断材料を作る。

前提：
- 定式化は 03_allocation.md の「定式化」。CPLEX LP 形式で渡し、変数名は連番（x1, x2, …）にする。
- R8 の実データはまだ fixtures にない（T05 で作る）。在庫と申請は、05_development.md の「R8 の実績」の表の合計に合うダミーを、シードを固定した乱数で作ってよい。
- オプションは solver: 'simplex'、random_seed: 0。

範囲：spikes/highs/ の下だけ。Node と、ブラウザ（最小の Vite ページを Playwright の Chromium で開く）の両方で測る。本体のパッケージは作らない。

完了基準：
- Node とブラウザで、それぞれ5回実行した時間の中央値が出ている。
- 解のすべての変数が整数（|x − round(x)| ≤ 1e-6）であることを確かめた。
- 同じ入力で5回とも同じ解になることを確かめた。
- 静的書き出しのアプリで wasm を読み込む方法（locateFile、ファイルの置き場所）が分かっている。

出力：notes/T00.md（結果の表、使った highs のバージョン、ブラウザでの読み込み方法、T06 への注意点）。spikes/ はマージしてよいが、本体からは参照しない。
