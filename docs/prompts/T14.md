推奨：モデル sonnet ／ effort medium

目的：/history を作り、SPEC.md の「E2E の検証手順」を Playwright で通しにし、運用の README を書く。

前提：04_screens_api.md の「履歴」、SPEC.md の「E2E の検証手順」、00_overview.md の「保守と引き継ぎ」。

範囲：apps/web の /history、e2e/、README.md（docs/runbook.md に分けてもよい）。

完了基準：
- CI で通しの E2E（ログイン → 年度の作成 → 在庫 → 申請 → 自動振り分け → 確定 → 出力 → 確定の解除 → 最小変更）が通る。

- 05_development.md の受け入れ基準のチェックボックスを、確かめたものから埋めた。

出力：変更ファイル一覧、実行したコマンドと結果、受け入れ基準で満たせなかった項目。
