# T09 画面：マスタ設定とダッシュボード
推奨：モデル sonnet ／ effort medium ／ 計画モードで開始

目的：/settings（年度の作成と前年度からの複製、場所・品目・団体・距離・ユーザーの招待・データの書き出し）と /（ダッシュボード）を作る。

前提：
- 04_screens_api.md の「ダッシュボード」「マスタ設定」。
- 書き込みは RLS の範囲なら直接、年度の作成・状態の変更・招待は RPC（create_year_from、set_year_status、invite）で行う。

範囲：apps/web の該当ページ。共通のレイアウト（ナビゲーション、ロールによる表示の切り替え、読み込み中・空・権限なしの表示）は T04 で作ったもの（components/layout、components/states.tsx、lib/navigation.ts）を使い、作った画面を lib/navigation.ts で ready にする（P-03）。今の年度の選び方（K-19。T04 は「ロールのある最新の年度」）を決め、必要なら年度の切り替えを足す。

完了基準：
- 管理者・部員・団体代表・未招待のテストユーザーで、それぞれ見えるものが権限表どおりになっている（Playwright）。
- 年度を作って前年度から複製すると、団体とルールが付け替わる。
- `pnpm build`（静的書き出し）が通る。
- 実際に起動して確認し、スクリーンショットを notes/T09/ に残す。

出力：変更ファイル一覧、実行したコマンドと結果、スクリーンショット。
