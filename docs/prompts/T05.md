# T05 importer と R8 の fixtures
推奨：モデル sonnet ／ effort medium

目的：Google フォーム回答の取り込み（parseFormCsv）を作り、R8 の元データから個人情報を除いた fixtures/r8 を生成する。

前提：
- 取り込みの仕様は 04_screens_api.md の「CSV取り込み」。フォームは模擬店・部門・企業の3種類。
- fixtures の作り方は 05_development.md の「fixtures/r8 の作り方」。剣道部は2団体に分ける。R8 で決めた読み替えの一覧を fixtures/r8/README.md に書く。
- R8 の元データ（フォーム回答の xlsx 3種類、机・椅子数え、最終の振り分け表）はリポジトリの外（環境変数 `R8_SOURCE_DIR`）にある。xlsx は CSV に書き出してから使ってよい。メールアドレスを含むので、ログやテストの出力にも出さない。

範囲：packages/importer、scripts/build-r8-fixtures.ts、fixtures/r8/、supabase/seed.sql への R8 データの追加。

完了基準：
- 3種類のフォームの取り込みテスト（列ずれの行、同じ団体の重複回答、企業名のない回答、どの列にあるメールも捨てる）が通る。テスト用の入力は匿名化したサンプルを使う。
- fixtures/r8 に、在庫・正規化した申請・R8 の手作業の振り分け（参考）が入り、在庫の合計が 05_development.md の「R8 の実績」の表と一致する。
- fixtures/ と supabase/seed.sql にメールアドレスがないことを、テストで確かめる。

出力：変更ファイル一覧、実行したコマンドと結果、読み替えの一覧（fixtures/r8/README.md）、判断が要った点。

---
終わったら：reviewer サブエージェントでレビューする（正しさと要件に関わる指摘だけ）。認証・RLS・RPC・入力処理に触れたら security-reviewer にも回す。指摘を直してから PR を作り、docs/requirements/05_development.md のチケット表の状態を更新する。
