# T07 validate() と、解けないときの診断
推奨：モデル sonnet ／ effort medium

目的：検証コード（E001〜E006、W101〜W107、I201）を返す `validate()` と、`allocate()` が解けないときの shortages・causes を実装する。

前提：03_allocation.md の「検証コード一覧」「解けないときの扱い」と、Issue の型。

範囲：packages/allocator の validate と diagnose。画面は T13。

完了基準：
- 各コードについて、出る入力と出ない入力の両方のテストがある。
- 申請を在庫より多くした入力で、shortages に品目と不足数が入る。S05 が原因の入力で、causes に S05 が入る。どのルールを外しても解けない入力で「複数の条件の組み合わせ」が返る。
- 診断の解き直しを含めて、R8 規模で2秒以内。

出力：変更ファイル一覧、テスト結果。
