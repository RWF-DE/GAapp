## B2 の原因と直し（シートの上のダイアログで後ろのシートが暗くならない）

**原因**：DOM の順と重なりは正しかった（T19 の直し・3 のとおり、body の直下に シートの覆い → シート → ダイアログの覆い → ダイアログ。どれも z-50 で、後ろのものが上）。覆いはどれも黒の半分（bg-black/50）なので、上に開いたダイアログの覆いは、シートの覆いの上にも重なる。ページは2枚の覆いで4分の1の明るさ、シートは1枚で半分の明るさになり、ずっと暗いページとの差で、シートが暗くなっていないように見えていた（撮影の絵を見たときも、計るまでは同じように見えた）。

本物のブラウザ（e2e:shots の一時的な spec。コミットしていない。PC 1280×800。提出状況のシートに差し戻しのダイアログを開く）で計った画素の値（白 255 の所。0〜255）：

| 状態 | ページ | シート | ダイアログ |
| --- | ---: | ---: | ---: |
| シートだけ（直す前・後とも） | 127 | 255 | — |
| ダイアログを開いた（直す前。main と同じ形。撮影の documents-return-dialog-pc〔d81d97a・24885c2〕も同じ値） | 63 | 127 | 255 |
| ダイアログを開いた（直した後） | 127 | 127 | 255 |
| ダイアログを閉じた後（直す前・後とも） | 127 | 255 | — |

直す前の getComputedStyle は、シートの覆いもダイアログの覆いも oklab(0 0 0 / 0.5)。直した後は、シートの覆いに data-covered が付いて rgba(0, 0, 0, 0)、ダイアログの覆いだけが黒の半分。

**直し**（04「共通レイアウト」のダイアログの重なりの2つ目の箇条・D-52 の FU3 の直しを先に書いた）：いちばん上の覆いだけが後ろを暗くする。
- components/ui/dialog-layer.tsx：DialogLayer が置かれている間だけ（参照の数で、最初の1つで始め最後の1つで止める）、MutationObserver で body の子の出入りと、body の直下の覆い（alert-dialog・dialog・sheet）の data-state を見張る。覆いを後ろ（上）から見て、より上に開いた（data-state="open"）覆いがあるものに印 data-covered を付け、ないものから外す。上の覆いが閉じ始めたら（data-state="closed"）すぐ外す。
- dialog.tsx・sheet.tsx・alert-dialog.tsx の覆いのクラスに `transition-[background-color] data-covered:bg-transparent` を足した（上の覆いの出入りの 150 ms と同じ長さで入れ替わる。書き出しの CSS は `.data-covered\:bg-transparent[data-covered]{background-color:#0000}`）。
- 1つだけ開いたときは印が付かないので、見た目（色・動き）と DOM は今までどおり。呼び手は直さない。
- 選ばなかった形：CSS の `:has(~ …)` だけで下の覆いを透明にする形は JS が要らないが、jsdom の Vitest でクラスの効き目を確かめられず（Tailwind の CSS はテストに入らない）、`:has()` のない古いブラウザでは今の見た目に戻るだけなのは同じなので、確かめられる印の形にした。
