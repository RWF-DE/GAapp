## B2 の原因と直し（シートの上のダイアログで後ろのシートが暗くならない）

**原因**：DOM の順と重なりは正しかった（T19 の直し・3 のとおり、body の直下に シートの覆い → シート → ダイアログの覆い → ダイアログ。どれも z-50 で、後ろのものが上）。覆いはどれも黒の半分（bg-black/50）なので、上に開いたダイアログの覆いは、シートの覆いの上にも重なる。ページは2枚の覆いで4分の1の明るさ、シートは1枚で半分の明るさになり、ずっと暗いページとの差で、シートが暗くなっていないように見えていた（撮影の絵を見たときも、計るまでは同じように見えた）。

本物のブラウザ（e2e:shots の一時的な spec。コミットしていない。PC 1280×800。提出状況のシートに差し戻しのダイアログを開く）で計った画素の値（白 255 の所。0〜255）：

| 状態 | ページ | シート | ダイアログ |
| --- | ---: | ---: | ---: |
| シートだけ（直す前・後とも） | 127 | 255 | — |

直す前の getComputedStyle は、シートの覆いもダイアログの覆いも oklab(0 0 0 / 0.5)。直した後は、シートの覆いに data-covered が付いて rgba(0, 0, 0, 0)、ダイアログの覆いだけが黒の半分。

**直し**（04「共通レイアウト」のダイアログの重なりの2つ目の箇条・D-52 の FU3 の直しを先に書いた）：いちばん上の覆いだけが後ろを暗くする。
