## 判断したこと

- **列の対応表（FORM_COLUMN_MAP）は仮**。本物のフォームの見出しを見ていない。タイムスタンプは「タイムスタンプ」、団体名は「団体名」「部門名」で始まる列（模擬店は複数列のうち空でない方）、備考は「備考」で始まる列、品目は見出しに items.aliases（NFKC・空白除去・長い方を優先）を含む列。合わなければ、必要な列がないという失敗（中身を含まないメッセージ）か ignoredColumns に出る。元データが届いたら見出しを突き合わせ、直すのは parse.ts の対応表だけ。
- ParsedForm.rejected の reason に `invalid_timestamp` を足した（設計 3.7 は misaligned・invalid_number・empty）。タイムスタンプが読めない行を、静かに捨てずに行番号つきで返すため。
- 数の列にメールがある行は `misaligned`（列がずれた行）にする。団体名・備考の中のメールは、その部分だけ取り除く。ほかの列（対応表にない列）は読まない。見出しがメールのパターンなら `(列N)` にする。
- 全角の数字・「3台」のような単位つきは読む。負数・小数・MAX_COUNT 超えは invalid_number。
- resolveResponses：名前・別名が 2 つの団体に当たる表記は対応させず unmatched にする。手で選んだ団体 id（manual）は名前より優先し、存在しない id は unmatched。申請できない品目で読み替え先もないもの（E006 候補）はそのまま残す。0 の行は持たない。出力は団体の入力順 → 品目の sort_order。
- CSV のパーサは importer に自前（ブラウザで動くため shared/testing は使えない）。行番号はレコード番号（セル内の改行は数えない）。
- 共通基盤（shared・shared/testing）は変えていない。scripts は importer を相対パス（`../../packages/importer/src/index`）で読み、ルートの devDependencies を増やさない（T07・T08 と package.json が衝突しないように）。
- build の入力の形（R8_SOURCE_DIR）は設計書にないので決めた（上の README の表）。元データの実際の形に合わせて直す。company.csv は行ごとに団体を選ぶ必要があるので company_map.csv（row,group）を別に置く。
- build の失敗：フォームの取り込めない行・対応しない行は既定で失敗（`--allow-rejected` で飛ばして続行）。想定外の例外は種類の名前だけを出す。ただしフォーム・CSV の形が読めない失敗（見出しが合わない・引用符が閉じていない）は、importer の `ImportFormatError`（メッセージに元データの値を入れない）で投げ、build が `forms/<種類>.csv: …` の BuildError にして表示する。
- reference の「残す」の行（S08）：運び元の部屋が rooms.csv で usable = false なら除く。使える部屋なら、manual/groups.csv で location がその部屋の団体の行にする（当たる団体がない・複数あるときは行番号つきで失敗）。計・合計・余り・使用不可と reference_skip.csv の使用用途は除く。団体別集計（allocation_totals）の「残す」の行は団体ではないので除く。
- 分ける団体（剣道部）は manual/settings.json の `splitGroups`（元の名前 → 並び順の団体名の配列）で指定する。申請より多い分は配列の最後の団体に付ける。分けた後の品目ごとの合計は、表の行の合計と一致するかを確かめる。集計シートの値と違うときは、2 団体とも group_totals.csv から除く。
- group_totals.csv は、集計シートにない団体は 0 として比べ、一致した団体を全部載せる（T08 の「載っている団体の数 = 団体数 − 除いた数」を成り立たせるため）。
- 備考は「キャスター机に交換」だけを許す（settings.json の allowedNotes で足せる）。それ以外は文言を出さず失敗。
- メールの検出（sanitize.ts）は、@ ごとに左右へ伸ばす方式（正規表現で local 部を先に探すと、@ のない長い列で時間が二乗になるため）。@ の前後の空白（8 字まで）と、ドメインの区切りの「。」を許す。local 部は長さを切らず全体を取り除く（5 万字のセルが 100ms 未満）。「。」を区切りに許すため、直後に日本語が続くと（`…。com。以上`）その続きの文字も取り除く（取りこぼすより多く取り除く側に倒した）。
- 読む列（団体名・数・備考・タイムスタンプ）のいちばん右の位置まで届かない短い行は `misaligned`（足りない列を 0 として取り込まない）。
- build：完全に空の行（reason が `empty`）は失敗にせず、件数だけを report（`空の行（取り込まない）`）に出す。anonymize.csv の source_name が manual/ の名前の欄（groups.csv の name・aliases・display_name、reference_skip.csv の use、settings.json の splitGroups のキー）に入っているときは、値を出さず anonymize.csv の行番号とファイル名・欄だけで失敗する（元の名前が fixtures に出るのを防ぐ）。reference_skip の use は匿名化の後の名前で当てる。
